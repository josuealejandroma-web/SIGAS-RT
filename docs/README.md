## Para instalar y probar

1. [Instalación desde cero en otro equipo](instalacion_otro_dispositivo.md): requisitos por modalidad, clonación, dependencias, arranque, pruebas y resolución de problemas.
2. [Manual del simulador](manual_simulador.md): uso de controles y escenarios.

4. [Gemelo web](../web-digital-twin/README.md): inicio rápido y estructura.
5. [Validación de instalación web](validacion_instalacion.md): comprobaciones realizadas y alcance.

La guía de instalación desde cero describe el lanzador MATLAB actual y sus sesiones persistentes. Los documentos de evidencia registran resultados de revisiones concretas y no garantizan que toda instalación nueva esté ya validada.
