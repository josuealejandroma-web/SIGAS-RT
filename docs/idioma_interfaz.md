# Idioma de la interfaz

La interfaz visible del gemelo digital está traducida al español para facilitar las demostraciones del simulador. Se tradujeron los encabezados, estados, eventos, escenarios, controles de reproducción, indicadores, modos de rendimiento y mensajes de conexión.

Se conservan identificadores técnicos que forman parte del modelo o de la telemetría, como `MATLAB_SIM`, `ADC`, `P0`, `P1`, `PK`, `PL`, `PT`, `VM`, `VK`, `VL`, `VT`, `mbar` y `kg/s`. Estos valores deben mantenerse sin cambios para que la visualización siga coincidiendo con el protocolo del gemelo digital.
